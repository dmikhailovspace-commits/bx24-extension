# Проверка загрузки времени 7.5.113

Одинаковые данные: 4149 задач, 108 нативных чатов, 321 собственная запись и 19260 секунд; выбраны все проекты и задачи без проекта. Браузер Chromium, CPU x4, контролируемый HTTP 80 мс с четырьмя каналами. Старый runtime извлечён из commit `812ee8a26473bcd6fa7d3c45067cee6c116d4902`, все 19 Git blobs сверены.

## Протокол 3

SDK-эмулятор исполняется в браузере. Раньше он копировал весь каталог по два раза для каждого 50-строчного ответа, создавая собственную нагрузку на главный поток. Теперь сначала фильтруются ссылки на строки, затем материализуются только возвращаемые объекты. 109 сравнений со старым алгоритмом проверяют ID-границы, порядок, группы, даты, смещения и изменения групп. Для страницы из 50 строк создаётся 50 объектов; исходные данные не изменяются. Сетевые задержки, выборка и все восемь лимитов производительности сохранены.

Обе версии заново измерены на этом протоколе. Результаты прежнего протокола 2 не используются для нового сравнения.

Ускорение: 21.35 раза на этом стенде. Старая версия превышает paint и long-task budgets; это сохранено в отчёте. Новая показывает p95 кадров 33.3 мс и long-task total 1459 мс. Итоговый релизный прогон измеряется отдельно и сохраняет собственные значения.

## Изменения runtime и проверки

- Каталог читается по непересекающимся диапазонам ID через ограниченные SDK-пакеты. Отсутствующие/неверные/частичные страницы не публикуются как полный результат.
- Только явный `TIME_SPENT_IN_LOGS=null` подтверждает пустой журнал. Число 0, строка "0", undefined и отсутствие поля сохраняют обычное чтение. Общая сумма задачи не используется как собственный итог дня.
- Поздний каталог не обнуляет подтверждённое добавление времени. Контакты и ACK сохраняют ревизионную защиту.
- Сегодняшний итог загружается без открытия панели. Сохранённый preview отделён от подтверждённого снимка; новая подходящая задача запускает точечное обновление и при закрытой панели.
- Геометрия: 101 вызов даёт 1 layout-read/1 CSS-write; проверены hide/show, замена viewport, перенос, рамка, padding, устаревшие callbacks и fallback без ResizeObserver.
- Фильтры: один проход на render, 2000 задач дают 2000 вызовов; следующий render учитывает изменение поиска, проекта, непрочитанных, названия, цвета и папки.
- Палитра исключает занятые цвета обоих списков и пустых папок, сохраняет заметное отличие от текущего цвета. Горизонтальный сдвиг устранён. Первичная настройка проверяется в узком и широком окне.

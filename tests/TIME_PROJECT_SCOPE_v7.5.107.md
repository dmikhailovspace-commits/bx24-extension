# Проекты и загрузка времени — 7.5.107

Обязательная настройка проектов ограничивает источник `tasks.task.list`, поиск и рабочий набор elapsed. Для новых профилей нет автоматического выбора всех проектов. Выбор сохраняется по порталу и пользователю; задачи без проекта включаются отдельно.

Один владелец сначала завершает каталог выбранных задач, затем читает время за подтверждённую дату портала. Native metadata не объявляет time membership. Если подходящий полный native каталог уже есть, он используется без повторного обхода. Ручное обновление делает полную сверку выбранных проектов, события — точечную инвалидацию. Таймер десятиисекундного обхода удалён.

Для явно выбранного полного охвата (все проекты и задачи без проекта) транспортный владелец общий с native-каталогом в обоих порядках запуска. Нулевой cursor не запускает delta. Проверки измеряют запросы с первого старта, а не только после открытия панели, и требуют отсутствия второго прохода.

Тесты покрывают обязательный первый шаг, сохранение и сбой storage, reload, all/unassigned, повтор страниц, чужой GROUP_ID, удержанный хвост каталога, запоздалые ответы при A→B→A, отдельные portal/user, перенос и удаление задач, подтверждённую запись после смены проекта, доступность интерфейса и размеры окна. Старые elapsed/CRUD VM fixtures явно задают завершённую настройку; отдельная project suite выполняет реальные production helpers без подмены membership.

Поиск доступен во время начальной загрузки. Добавление времени и запуск таймера становятся доступны после подтверждения принадлежности выбранной задачи каталогу проектов. UI-тест удерживает ответ каталога, выбирает найденную задачу в обеих формах и проверяет отсутствие преждевременных записей, затем освобождает ответ и проверяет доступность кнопок.

В `native-startup-time-contention` сохранён полный сценарий 4149 задач и 321 записи. Дополнительно тот же портал проверяется с одним проектом из 149 задач; ожидание — 3 страницы выбранного каталога, 149 уникальных elapsed, 720 секунд и отсутствие повторных чтений при первом открытии панели. Это проверка количества работы, а фактическое время и CPU записываются отдельно.

Артефакты: `time-project-scope-report.json`, `time-project-layout-report.json`, `time-project-settings-ui-report.json`, `native-startup-time-current.json`, `regression-summary.json`.

Проверка использует Chromium, управляемый SDK и локальный HTTP. Она не заменяет проверку установленного расширения на реальном портале или физическом Mac. Фактический результат полного релизного прогона и хеши установщиков фиксируются после его завершения.

API: [tasks.task.list](https://apidocs.bitrix24.com/api-reference/tasks/tasks-task-list.html), [семантика массивов фильтра задач](https://www.dev.1c-bitrix.ru/api_help/tasks/classes/ctasks/getlist.php).

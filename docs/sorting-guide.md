# Как пользоваться сортировкой

1. Откройте **Правила** в панели чатов или задач. Для этих двух режимов настройки отдельные.
2. Добавьте правило: условия → папка. Например, «Исполнитель — Яна Ушакова» → «Яна У.». Сотрудника выбирайте из результатов поиска.
3. Расположите правила по приоритету. Проверка идёт сверху вниз, побеждает первое совпадение. Точное правило для сотрудника обычно стоит выше общего правила проекта.
4. Нажмите **Проверить**: это предпросмотр, он ничего не переносит. Затем **Сохранить**.
5. Новые диалоги без назначения распределяются автоматически. Чтобы охватить прежние диалоги без папки, при сохранении отметьте **Распределить уже существующие диалоги**. Ручные решения и исключения защищены.
6. Если задача уже в папке и условия изменились, откройте **Пересортировку**. При выключенном автоподтверждении задача останется на месте до вашего подтверждения.

**Если подходят два правила.** Например, вы — постановщик задачи, а Яна — исполнитель. Правило для вас и правило для Яны могут совпасть одновременно. Папку определит то, которое стоит выше. Если важнее исполнитель, поднимите его правило выше правила постановщика и сохраните порядок.

**Если нужно оставить диалог.** «Пропустить» закрывает конкретное предложение до изменения его условий. Постоянное исключение запрещает дальнейшие автоматические переносы. Вернуть диалог можно в разделе «Исключения» кнопкой «Снова предлагать переносы».

**Если нужна полная автоматизация.** Во вкладке «Пересортировка» есть отдельный переключатель «Автоматически подтверждать переносы». Его включение применяет и текущие предложения — перед этим появляется подтверждение. В этом обновлении ваша настройка не менялась.

Изменения задач проверяются по событиям Bitrix. Пропущенные события подхватывает фоновая сверка небольшими пакетами при видимой открытой вкладке, включённом расширении и наличии сети. Если данных не хватает, расширение сначала уточнит их. Большой каталог не перепроверяется мгновенно.

Эта справка также доступна по кнопке **Инфо** в панели правил.

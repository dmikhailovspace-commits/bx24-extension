# Перенос правил и пересортировка: локальный предпросмотр 8.0.67

Дата: 09.11.2026. Публикация не разрешена для этой правки; GitHub Release, Chrome Web Store, update channel и Яндекс Диск не изменяются.

## Что исправлено

- Экспорт больше не выбрасывает имя выбранного сотрудника. Проверка ID отделена от отображения имени; старый импорт без имени восстанавливает его по ID в редакторе. Неудачный запрос имени не заменяет ID другим пользователем.
- При вводе двух символов старая подсказка немедленно сменяется на «Поиск…». Добавлены Unicode/NFC, IME и защита от ответов предыдущего запроса.
- Обязательные условия проверяются через AND, остальные — в выбранном режиме любое/все. Неизвестные данные не разрешают автоматический перенос.
- Автоподтверждение задаётся отдельно для чатов и задач. По умолчанию выключено, после импорта выключается. Исключения и одноразовые пропуски сохраняются.
- Имя сотрудника, тип представления его ID и порядок участников не сбрасывают ранее пропущенное предложение. Журнал фактов мигрирует на factsOrderVersion 2.
- Исключения сгруппированы в плавный аккордеон, добавляются через настоящий контекстный пункт и поддерживают переход к диалогу. Мультиселект и смена пользователя защищены.
- Ошибка записи журнала не меняет назначение в памяти. Исключённый диалог не показывает устаревший тикет даже при ошибке очистки журнала.

## Проверки

- `rules-required-transfer-model`: 912 утверждений, включая 216 комбинаций обязательных/обычных условий и канонические факты.
- `rules-priority`: 12 сценариев, включая 324 комбинации пересечения правил.
- `rules-resorting`: 12 сценариев переключения режима, пропусков, исключений, legacy-журнала, неизвестных данных и ошибок записи.
- `rules-people-picker`: четыре фазы, Unicode/IME, действительный импорт файла, старый ID-only импорт, поздние ответы и повтор после ошибки.
- `rules-settings-ui`: три фазы, обязательность/черновики, аккордеон, навигация, внешнее изменение, reduced motion, ширина 360 px.
- `rules-context-exclusions`: шесть сценариев настоящего правого клика, мультиселекта и смены пользователя для чатов/задач.
- `rules-preview-races`: девять фаз. Совместный целевой прогон семи зарегистрированных наборов: 7/7 за 40,5 s.
- Ранее в текущей правке: settings-transfer UI, восемь сценариев storage/quota, transfer-model-async, performance 4 000 / 10 000 диалогов. На 10 000: открытие 10,4 ms, сборка 40,7 ms; это измерение fixture, не обещание скорости реального портала.
- Финальный runtime зафиксирован в `534d7e023f328b490e107a42ee90c57b6f382417`. Точный search-focused: **16/16 за 366,5 s**. Финальный folder-automation и повтор контекстных исключений также прошли. Полный набор 105 тестов не запускался.
- Первая попытка search-focused обнаружила изменение привычного порядка первых трёх действий ПКМ. Пункт исключения перенесён после цветового маркера; исходный assert сохранён, профиль повторён полностью.
- Анимация исключений измерена через requestAnimationFrame: раскрытие 0→268 px, закрытие 268→0 px, по 11 промежуточных высот; быстрое открытие–закрытие–открытие корректно завершилось. Проверена ширина 360 px и reduced motion.

## Границы проверки

Использованы синтетические порталы Chromium и Chrome MV3. Живой Bitrix24, нативный CEF и физический Mac не проверялись. Исходный симптом с двумя обычными кириллическими буквами напрямую не воспроизведён: прежний код уже проверял `<2`; добавлены защита подсказки/Unicode и тест реального последовательного ввода. Потеря имени при экспорте подтверждена и воспроизведена. Валидный ID без имени сам по себе ранее продолжал совпадать в модели.

Навигационный UI-тест проверяет вызов существующего помощника и сохранение исключения; сам помощник там заменён тестовым. macOS DMG в этой локальной Windows-сборке не создаётся.

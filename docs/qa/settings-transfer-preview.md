# Настройки и перенос — предпросмотр от 08.11.2026

Этот комплект содержит исправления после опубликованной 8.0.66. Номер пока сохранён только для внутренней проверки. Он ещё не заменяет сборку в Chrome Web Store, GitHub Release или канале автообновления.

## Что изменилось

- Исправлен экспорт обычных чатов без номера задачи.
- Перенос работает через JSON-файл или код. Если приложение не скачивает файл или не разрешает копирование, код можно выделить и скопировать вручную.
- Импорт проверяет данные до подтверждения и показывает количество папок, диалогов и правил. Чужой портал или пользователь, повреждённые данные и слишком большой файл отклоняются.
- Изменение кода или настроек отменяет прежнюю проверку. Последний импорт можно отменить, в том числе после повторного открытия окна.
- Панель настроек получила группы управления и один свёрнутый раздел «Дополнительно». Новых вкладок нет.
- Удалены показатели пересечений правил и их фоновый подсчёт. Приоритет, перетаскивание и подтверждения переносов сохранены.

## Открыть в Chrome

1. В chrome://extensions отключите магазинную копию сортировщика.
2. Включите «Режим разработчика» и выберите «Загрузить распакованное расширение» → папку unpacked из этого комплекта.
3. Подключите свой портал и обновите вкладку Bitrix24.
4. Откройте «Фильтры → Дополнительно → Перенос настроек».

Для возврата отключите предпросмотр и включите магазинную копию. Настройки того же портала общие: подтверждённый импорт меняет их. Его можно отменить через кнопку «Отменить последний импорт».

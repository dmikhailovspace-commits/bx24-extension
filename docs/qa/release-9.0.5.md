# Выпуск 9.0.5 — сверка условий задач

Дата: 17.11.2026. Ветка `codex/reconcile-task-folders-9.0.5`, изолированная от исходной рабочей папки пользователя.

## Причина и исправление

Существующий планировщик запрашивал задачи только при неполных условиях или dirty-событии Pull. Полностью заполненные, но устаревшие факты не перепроверялись. Новый тест на 9.0.4 воспроизвёл старого исполнителя и прежнюю папку после visibilitychange; запросов tasks.task.get не было.

Фоновая сверка берёт известные доступные задачи без постоянных исключений, по 50 ID через tasks.task.list. Срок явного API-чтения — 120 секунд; после запуска кэш сам по себе не считается свежим. Отметки в памяти привязаны к аккаунту и началу запроса. Между пакетами минимум секунда, detail-обновления имеют приоритет. Ошибка или пропущенная строка оставляют данные и дают минутную паузу. Видимость, сеть, включение, аккаунт и ревизия Pull проверяются до записи. Более ранний API-ответ не откатывает более поздний.

Подтверждение переносов не менялось: при выключенной автоматике новая информация создаёт предложение; включённая автоматика использует прежний механизм. Не выполняются прокрутка native-списка, отправка сообщений или редактирование самих задач.

Контракт API: https://apidocs.bitrix24.com/api-reference/tasks/tasks-task-list.html. Предел страницы — 50; выбираются все изменяемые поля правил.

## Проверки

- rules-live: пропущенный Pull → ручное предложение, периодическое обновление без событий, перезапись кэша без продления свежести, 65 задач пакетами с исключением, ошибка/backoff, пропущенная строка/retry, Pull во время ответа списка, offline/online и прежние шесть живых сценариев.
- rules-resorting: ручное подтверждение, автоматическое подтверждение, исключения, пропуск предложения, приоритет, отсутствие данных и нехватка места.
- folder-automation: модель, редактор, preview, сохранение, новая задача, конкурентные изменения и размеры окна. Изолированный тест detail/deadline отключает только независимый фоновый таймер; тот проверяется полным runtime в rules-live.
- release-integrity и проверка PROJECT_CONTEXT; далее обязательный CI search-focused 16 и прежние дополнительные gates перед сборками.

## Живое наблюдение и ограничения

Разрешённый пользователем Computer Use подтвердил в Chrome версию 9.0.4, включённое правило «Яна» (исполнитель либо постановщик Яна Ушакова → папка «Яна У.»), выключенное автоматическое подтверждение и пустую очередь. Пользователь прямо потребовал сохранить эту настройку. Конкретная задача 88494 пока не проверена; причинный сценарий воспроизведён на тестовом портале. Физический Mac не запускался.

## Изменения

В редакторе правил im.search.user.list может отклонить двухсимвольный запрос с FIND_SHORT из-за внутреннего поискового фильтра. Раньше повтор отправлял тот же запрос и снова давал ошибку. Теперь только этот отказ для двух NFC-символов переключает запрос на user.search с FILTER.FIND. Поля каталога нормализуются в существующие числовой ID и подпись. Пагинация продолжает выбранный метод с его собственным next/start. Настоящие ошибки сохраняют возможность повтора; смена запроса, аккаунта, режима и поколения отсекает поздний ответ.

Контракт Bitrix: https://apidocs.bitrix24.com/api-reference/chats/search/im-search-user-list.html и https://apidocs.bitrix24.com/api-reference/user/user-search.html. Первый метод документирует минимум два символа, но также отдельный отказ внутреннего фильтра; второй выбирает полнотекстовый или префиксный поиск и возвращает страницы по 50.

Список сотрудников и проектов имеет фиксированную позицию вне потока формы и непрозрачный белый фон. Popover API поднимает его в верхний слой браузера. Без API остаётся fixed-позиционирование. Ширина соответствует полю, доступная высота ограничивает список; при необходимости он раскрывается вверх. Обработчики прокрутки и размера окна живут только во время показа. Escape, выбор, уход фокуса, сворачивание/перерисовка и закрытие снимают слой.

## Проверки

Новый сценарий rules-people-picker на исходной 9.0.3 воспроизвёл отсутствие результата после FIND_SHORT. Исправленная версия прошла:

- два символа, Unicode/NFC, IME, пустой ответ и старый ответ;
- fallback с uppercase-полями каталога, следующую страницу start=50 и повтор после ACCESS_DENIED;
- опоздавший ответ fallback после нового трёхсимвольного запроса;
- сохранение выбранного ID и подписи при импорте и перерисовке;
- отсутствие сдвига следующего условия, непрозрачность и elementFromPoint поверх его поля;
- границы окна высотой 540 px, Escape без закрытия редактора и выбор клавиатурой.

Локально PASS: rules-people-picker, folder-automation, release-integrity, project-context. Дополнительно во встроенном браузере на стенде вручную введено «Ан» при имитации FIND_SHORT: сотрудник найден, нижнее поле перекрыто. Снимок: tests/artifacts/rules-people-overlay.png.

Тот же набор правил дополнительно прошёл в Chromium с отключённым HTMLElement.prototype.showPopover (до загрузки runtime). Это подтверждает fixed-fallback, перехват клика, границы окна и клавиатуру без Popover API, но не является запуском старого CEF. Доказательства: tests/artifacts/rules-people-picker-no-popover.json и rules-people-overlay-no-popover.png.

Профиль CI сохраняет точный search-focused 16, существующие transfer/storage, восемь наборов правил и семь наборов времени. Полный реестр не запускался.

## Ограничения

Код отказа портала пользователя не перехватывался: FIND_SHORT выбран по документированному контракту и симптому «два символа не работают, три работают».

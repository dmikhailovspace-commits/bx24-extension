# Предпросмотр переноса настроек 8.0.67

Это тестовая сборка. Номер остаётся 8.0.67 до утверждения пользователем. Публичные релиз, автообновление, Яндекс Диск и Chrome Web Store не обновляются.

## Исправления

- Код для переноса заполнен сразу при открытии окна. Кнопка под кодом показывает «Скопировано» только после успешного копирования.
- Код обновляется сразу после импорта и отмены. При запрете буфера доступно ручное копирование.
- Окно имеет единые отступы, состояния наведения/фокуса и короткие анимации. Заголовок и действия остаются доступными в узком или коротком окне.
- Резервная копия больше не занимает ограниченный localStorage. До переноса она сохраняется в IndexedDB вместе с журналом восстановления. При обычной ошибке записи исходные настройки возвращаются; после аварийного прерывания доступна явная отмена.
- Привычная панель фильтров сохранена.

- Восемь сценариев хранилища: настоящее переполнение localStorage, частичный отказ записи, отказ IndexedDB, прерванная финализация, перезагрузка, явное восстановление, устаревший пользователь/закрытие окна, прежний формат копии.

# Выпуск 9.0.3 — живая автосортировка задач

Дата: 16.11.2026. Неизменяемый источник: `cfd09623128ac6a9e626fcb70b3b2f5dcceaa5d9`, тег `v9.0.3`. CI: https://github.com/dmikhailovspace-commits/bx24-extension/actions/runs/43924128507.

## Исправление

Частичный Pull больше не подтверждает актуальность старых условий. Событие инвалидирует факты задачи и ставит точечное перечитывание в существующую ограниченную очередь. Смена ревизии во время запроса отсекает запоздавший ответ.

Новая задача обрабатывается и до появления нативной строки: task ID из события разрешается через tasks.task.get, CHAT_ID добавляет метаданные в существующий каталог. Строка без task ID разрешается через im.dialog.get. Нет нового неограниченного polling или параллельного REST-планировщика.

После изменения метаданных повторно применяется полная видимость списка по папке и фильтрам. Строка исчезает из старой папки и видна в новой без перезагрузки. Сохранены ручные исключения, снимок активации и настройка автоматического подтверждения переносов.

## Проверки

Новый rules-live: шесть успешных браузерных сценариев — неполное событие, task_add до строки, строка без task ID, матрица всех изменяемых условий, гонка ответов, подтверждение при выключенном автопереносе. Старая 9.0.2 не проходит четыре из первых пяти сценариев. Проверка нативной строки включает переход видна в A → скрыта в A → видна в B на том же DOM-узле.

Локально также прошли rules-resorting (22 сценария), rules-priority, rules-required-transfer-model (912 утверждений), folder-automation и project-context. Первый сокращённый прогон остановился на изолированной VM-фикстуре без новой зависимости merge; второй — на старом статичном ответе сервера после Pull. Фикстуры исправлены без ослабления проверок. Полный успешный профиль должен подтверждаться итоговым CI, локальный полный успех не заявляется.

Релизный профиль: точный search-focused 16 плюс прежние проверки правил, transfer/storage, семь проверок времени и новый rules-live. Обе desktop-сборки и Chrome package зависят от их успеха. Полный реестр не запускается.

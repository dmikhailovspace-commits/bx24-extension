# Внутренний предпросмотр 8.0.66 — правила сортировки

Проверенная пересборка 8.0.66 опубликована в GitHub из source cf006f1. Этот локальный комплект содержит тот же код. Пакет Chrome Web Store отправлен на проверку с автоматической публикацией после одобрения; публичная версия на момент отправки — 8.0.65. Публичный канал автообновления проверен.

Если уже установлена прежняя 8.0.66, обновите её вручную: номер сохранён по запросу, поэтому проверка более новой версии не обнаружит пересборку.

## Что исправлено

- У каждого правила есть тумблер в свёрнутой карточке. Выключенное правило сохраняется вместе с условиями и позицией, но не участвует в сортировке.
- Правила переносятся за ручку слева: зажмите ЛКМ и отпустите у синей линии вставки. Верхнее подходящее включённое правило имеет приоритет. Изменения применяются кнопкой «Сохранить».
- Жёлтая пометка «Пересечение» показывает, что одни и те же диалоги подходят правилам с разными папками. «Проверить» показывает примеры и победителя. Неизвестные данные не считаются подтверждённым совпадением.
- Перестановка правил не возвращает пропущенное предложение, если перенос остаётся тем же. Изменившаяся папка для существующего диалога требует подтверждения.
- В окне обновления сначала показано краткое «Что нового». Под ним — пояснение о способе обновления. Это добавлено в Chrome и общий код настольных версий.
- Сохранённые правила свёрнуты при каждом открытии панели. Новое правило и правило с ошибкой раскрываются для редактирования.
- Неизвестный исполнитель, участник или статус больше не считается выполненным условием «не равно». Обрабатываются неполные ответы Bitrix и разные формы списка участников.
- Новое название обычного или личного диалога попадает в правила. Для уже распределённого диалога появляется предложение в «Пересортировке»; папка меняется после подтверждения.
- Свежие изменения задачи не затираются запоздавшими ответами каталога. После временной ошибки недостающие сведения запрашиваются повторно с увеличивающейся паузой.
- «Проверить» учитывает уже распределённые диалоги, дочитывает недостающие сведения задач без сохранения правила и не меняет папки. Повторная проверка продвигается дальше первых десяти задач.
- Закрытие окна, редактирование и сохранение отменяют устаревший результат предпросмотра. Пропущенный перенос не обещается как автоматический.
- Кнопка «Добавить условие» не теряет клик при открытой подсказке поиска сотрудника.
- Скрытая аватарка автора остаётся скрытой в исходящих и системных сообщениях.

## Проверки

Матрица условий: 517 проверок, все 10 доступных полей, операторы, совпадения и несовпадения, неизвестные данные, сочетания «Все/Любое», приоритет правил. В интерфейсе задач доступны 9 полей; «Тип диалога» относится к обычным чатам.

Дополнительные наборы проверяют настоящую MV3-сборку в изолированном Chromium, работу редактора, поступление личного диалога, переименование, подтверждение переноса, отложенные ответы и перезапуск. Для интеграционных проверок используется тестовый Bitrix с синтетическими данными. Это не проверка на авторизованном рабочем портале.

Полный повторный прогон: **96/96 PASS**, 26 мин 23 с, без повторных запусков. Дополнительно: 324 комбинации приоритетов, 12 сценариев журнала, 7 фаз перетаскивания и тумблеров в настоящей MV3-сборке, 9 фаз гонок предпросмотра и пересечений.

## Как открыть предпросмотр

Если предпросмотр уже загружен из `E:\Codex\Previews\BX24-8.0.66-rules\unpacked`, нажмите «Обновить» на его карточке в `chrome://extensions`, затем обновите вкладку Bitrix24. Повторно добавлять расширение не нужно.

1. В `chrome://extensions` отключите магазинную версию сортировщика, чтобы две копии не работали одновременно.
2. Включите «Режим разработчика» → «Загрузить распакованное расширение» → выберите папку `unpacked` из комплекта предпросмотра. При переносе на другой компьютер сначала распакуйте Chrome ZIP в постоянную папку и выберите её.
3. В окне расширения укажите адрес своего HTTPS-портала и подключите его.
4. Обновите вкладку Bitrix24, откройте чаты и панель правил.

Для возврата отключите тестовую копию, включите магазинную и обновите вкладку. Предпросмотр использует настройки сортировки того же портала: подтверждённые изменения папок сохраняются. Для проверки на своих данных можно предварительно сохранить файл через «Настройки → Дополнительно → Перенос настроек».

## Что проверить на рабочем портале

- При открытии панели все сохранённые правила свёрнуты.
- Выключенное правило не выбирается победителем. Включение возвращает его на прежнее место с прежними условиями.
- Перетаскивание меняет приоритет; Escape отменяет перенос. Порядок применяется после сохранения.
- Пометки пересечений обновляются при смене условий; правила в одну папку не помечаются как конфликтующие.
- «Проверить» показывает ожидаемые совпадения по названию и выбранным участникам.
- Новый подходящий диалог попадает в папку по правилу.
- Изменение названия или исполнителя у уже распределённого диалога создаёт предложение в «Пересортировке».
- «Пропустить» сохраняет папку; постоянное исключение не предлагает перенос снова; подтверждение переносит диалог.

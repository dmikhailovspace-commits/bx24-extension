# Политика конфиденциальности

Сортировщик чатов Bitrix24 для Chrome.

Версия документа: 8 сентября 2026 года. Описываемая сборка: 7.5.113.

Автор: Разработчик расширения.

## Какие данные обрабатываются

После разрешения доступа к HTTPS-порталу расширение читает его интерфейс и использует API Bitrix24 в рамках прав текущей учётной записи. Для папок, фильтров, поиска и учёта времени обрабатываются:

- Адрес портала, числовой ID пользователя, идентификаторы чатов, задач, проектов и участников; доступные имена и адреса аватаров.
- Названия чатов и задач, фрагменты последних сообщений, сведения об их авторах и времени, признаки непрочитанного, упоминаний и отложенного чтения.
- Сведения о проектах, ответственных, статусах и возможности учитывать время; собственные записи времени, их даты, длительность и комментарии.
- Настройки папок, групп, цветов, сортировки и фильтров, поисковые запросы, выбранные проекты и черновики ручного ввода.
- Локальные события работы с задачей: её ID, момент взаимодействия, квалифицированные контакты, состояние таймера и состояние подтверждения записи.

«Контакт» означает взаимодействие с задачей. Он квалифицируется после 60 секунд видимого просмотра либо подтверждённой отправки собственного сообщения в чате задачи, если учёт времени разрешён. Это не сбор адресной книги. Сам контакт не записывает часы в Bitrix24. Расширение не ведёт историю посещения посторонних сайтов и не записывает все нажатия клавиш.

Для авторизованных операций используются существующий SDK и сессия Bitrix24. При некоторых действиях код получает токен сессии `sessid` из страницы и передаёт его обратно этому порталу. Собственную форму пароля расширение не предоставляет; пароль пользователя в его хранилище не сохраняется.

## Для чего нужны данные

Данные используются для отображения и организации чатов, поиска и фильтрации задач, подсчёта собственного времени, восстановления интерфейса после перезагрузки и защиты от повторных записей. Добавление, изменение или удаление записи времени выполняется по действию пользователя. Локальные контакты помогают выбрать задачу для ручного учёта.

Использование данных ограничено этими функциями. Расширение не продаёт рабочие данные, не использует их для рекламы, оценки кредитоспособности или обучения моделей и не отправляет их в сервис аналитики. Использование пользовательских данных соответствует ограничениям Limited Use политики Chrome Web Store в части описанных функций; это заявление о способе использования данных, а не отметка об одобрении расширения Google.

## Где данные хранятся и кому передаются

Кеш каталога и часть настроек находятся в `chrome.storage.local` профиля Chrome. Краткоживущие блокировки могут находиться в `chrome.storage.session`. Настройки интерфейса, контакты, черновики, состояние таймера, незавершённые операции и сохранённый итог дня находятся также в `localStorage` самого портала. Каталоги и учёт времени разделены по порталу и подтверждённому пользователю; часть настроек оформления действует на уровне сайта или профиля браузера.

Эти данные не синхронизируются расширением через `chrome.storage.sync`. Они не шифруются отдельным механизмом расширения: защита локального профиля зависит от браузера, операционной системы и доступа к устройству. `localStorage` портала доступен также скриптам этого сайта. Не используйте общий профиль браузера как средство изоляции конфиденциальных данных между людьми.

Для чтения и изменения данных выполняются запросы к подключённому Bitrix24 с текущей авторизацией. Отображение аватаров может загружать изображения по адресам, которые предоставил портал, включая его внешние хранилища. Их обработка определяется владельцем портала и соответствующими сервисами. В коде Chrome-сборки нет отправки рабочих данных на сервер разработчика, проверки обновлений через GitHub и ссылки на отдельный внешний сайт отчётов. Код, стили, значки и шрифты расширения включены в установочный пакет.

Разрешение выдаётся для выбранного HTTPS-хоста. Chrome не разделяет это разрешение по портам. Сайты без разрешения не подключаются. Работа самого Bitrix24, браузера и Chrome Web Store регулируется их собственными правилами обработки данных.

## Срок хранения и удаление

У локальной истории контактов и настроек нет общего автоматического срока удаления. Кеши обновляются по мере работы; сохранённый итог дня заменяется новым снимком. Очередь контактов и сведения о незавершённой записи сохраняются для восстановления после сбоя. Снятие разрешения или отключение расширения само по себе эти данные не удаляет.

Чтобы прекратить работу, отключите расширение или отзовите доступ к порталу и перезагрузите его вкладки. Удаление расширения очищает его собственное хранилище Chrome, но данные расширения в `localStorage` портала могут остаться. Их можно удалить вместе с данными этого сайта через настройки Chrome; такая очистка затронет и другие локальные данные Bitrix24 и может завершить вход. Перед очисткой завершите таймер и проверьте незавершённые записи: удалённую локальную очередь восстановить нельзя.

Удаление расширения или локального кеша не удаляет записи, уже сохранённые на сервере Bitrix24. Их изменяют в Bitrix24 или через панель времени при наличии соответствующих прав. Срок хранения серверных данных определяет владелец портала.

## Диагностика и связь

Технические сведения об ошибках и состоянии загрузки доступны локально в консоли и диагностических средствах расширения. Автоматической отправки отчётов разработчику нет. Если вы сами передаёте снимок экрана или диагностический файл поддержке, проверьте его на названия задач, сообщения и идентификаторы.

Для связи используйте контакт разработчика в карточке расширения. Вопросы о серверных записях и правах доступа также решаются с администратором вашего Bitrix24.

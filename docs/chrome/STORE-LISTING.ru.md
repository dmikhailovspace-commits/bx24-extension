# Тексты карточки Chrome Web Store

Тексты подготовлены для сборки 8.0.65. Пакет отправлен на проверку 04.11.2026.

## Название

Сортировщик чатов Bitrix24

## Краткое описание

Папки, фильтры, цветовые метки и учёт времени по задачам в веб-интерфейсе Bitrix24.

## Полное описание

Сортировщик чатов помогает навести порядок в Bitrix24: распределяет диалоги по папкам, выделяет проекты цветом и помогает быстро находить нужное. Можно работать с несколькими чатами сразу и учитывать время по задачам. Для работы нужен доступ к вашему порталу Bitrix24. Это независимое расширение.

## Single purpose

Организация работы с чатами и связанными задачами в Bitrix24: папки, поиск и фильтры помогают выбрать рабочую задачу, а панель времени позволяет учитывать выполненную по ней работу.

- Язык: русский. Категорию продуктивности/управления рабочими процессами выберите из актуального списка кабинета.
- Privacy policy URL: публичный адрес окончательной политики; в исходниках адрес не задан.
- Издатель: Dmitry Mikhailov. Контакт поддержки: d.mikhailov.space@gmail.com. URL главной страницы и поддержки в карточке: https://www.dmitrymikhailov.com/ (редирект на личный сайт).

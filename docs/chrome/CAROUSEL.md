# Карусель Chrome Web Store

Пять слайдов 1280×800, загружать в этом порядке:

1. `assets/carousel-01-folders.png` — папки и цветовые метки.
2. `assets/carousel-02-rules.png` — автоматические правила и подтверждение переносов.
3. `assets/carousel-03-bulk.png` — массовое закрепление, скрытие и пересортировка.
4. `assets/carousel-04-focus.png` — непрочитанное и отложенное.
5. `assets/carousel-05-time.png` — учёт времени по задачам за день, 7 и 30 дней.

Это маркетинговые иллюстрации функций на демонстрационных данных, не фотографии пользовательского портала. Макеты интерфейса упрощены. Фактические кадры Chrome runtime на синтетическом портале также сохранены в `screenshot-chats.png` и `screenshot-time.png` для проверки и альтернативной публикации; не добавлять их поверх пяти слайдов.

Два прежних одинаковых сюжета `screenshot-promo-wide.png` и `screenshot-promo.png` удалены из актуального комплекта. Маленькая и широкая промоплитки предназначены для отдельных полей Store, не для карусели.

Стиль основан на типографических принципах dmitrymikhailov.com: широкие геометрические заголовки в характере Unbounded, основной текст в характере Onest, строгая сетка, тонкие линии и монохромный контраст. Фон сайта не копировался. Растровый набор сгенерирован встроенным image_gen; исходные мастер-файлы, промпты и контрольные суммы находятся в `chrome/marketing/carousel/` исходного репозитория. Растровые надписи являются интерпретацией шрифтов моделью, не набором настоящими font-файлами.

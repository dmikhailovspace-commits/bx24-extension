Добавлен перенос папок, правил и распределения диалогов между приложением и Chrome через JSON-файл. Он находится в разделе «Фильтры → Настройки → Дополнительно → Перенос настроек». Перед импортом показывается состав файла; изменения применяются после подтверждения, с возможностью отменить последний импорт. Файл предназначен для того же портала и пользователя.

Убрано уведомление о диалогах, отсутствующих в текущем списке Bitrix. Их привязки к папкам сохраняются. Исправлено обрезание подсказки обновления в Chrome. Рядом с включением добавлена малозаметная подпись by Dmitry Mikhailov.

Сокращены повторные обходы списка при расчёте счётчиков папок и обновлении мультивыбора. Неизменённый порядок вкладок больше не записывается в хранилище при каждой отрисовке.

Проверка выпуска: профиль search-focused, 16 наборов; сценарии Chrome выполняются на тестовом портале с демонстрационными данными. Сборка Universal DMG проверяется на macOS в CI; запуск на физическом Mac не выполнялся.

Дополнение к этой же версии по запросу пользователя: подпись by Dmitry Mikhailov больше не является ссылкой. Уменьшены повторные вычисления счётчиков групп и сортировки; настройки фильтра читаются один раз на проход. Результаты сравнены с прежней сборкой на 1000–10000 диалогов.

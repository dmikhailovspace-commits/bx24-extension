# Скорость сортировки и понятные правила

Пользователь поручил выбрать реализацию самостоятельно. Цель — минимум трёхкратное улучшение измеряемой нагрузки расширения, без потери функций. Ускорение всего компьютера нельзя вывести из браузерного стенда.

Сохраняем упорядоченные правила, первое совпадение, отдельную первую классификацию и пересортировку, ручное подтверждение, исключения и защиту от устаревших ответов. Почтовые клиенты подтверждают понятность порядка правил, но буквальная обработка только входящих не подходит для изменяемых задач.

Вместо полного пересчёта после любого API-ответа отделяем свежесть чтения от изменения данных. Неизменившийся пакет продолжает сверку без перерисовки и пересчёта. При изменении сохраняется прежний путь применения. Инварианты аккаунта, событий, сроков, backoff и доступности не меняются.

В панели появляется вкладка-кнопка «Инфо». Она объясняет условия, приоритет, сохранение/предпросмотр, старые и новые диалоги, очередь, автоподтверждение, исключения и пример смены исполнителя. Черновик правил сохраняется при переключении вкладок.

План: сравнительный профиль 4000 задач → адресные оптимизации → проверка живых правил и интерфейса → повторный профиль и точные 16 релизных наборов с существующими дополнительными gates → единый релиз 9.0.6, автообновление, Store, Диск.
